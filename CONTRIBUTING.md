# Contributing

- Every statement in a skill must be verifiable in the [EvoPdf Next API reference](https://www.evopdf.com/help/evopdf-next-dotnet/). Link the page when you add or change a member.
- Keep samples minimal and runnable; no license keys, no environment-specific paths.
- One skill per task area; put long tables in a reference file next to `SKILL.md` and link it.
- The CI check validates the skill front matter and rejects license keys; make sure it passes before opening a pull request.
