# EvoPdf Next — headers and footers

Two mechanisms, both on `HtmlToPdfConverter.PdfDocumentOptions` (Word/Excel/RTF/Markdown converters expose the same options object).

## 1. HTML templates (recommended — full control)
```csharp
var footer = converter.PdfDocumentOptions.PdfHtmlFooter;   // PdfHtmlHeaderFooter
footer.Html = "<div style='font:10px Arial;text-align:right'>Page {page_number} of {total_pages}</div>";
footer.HtmlBaseUrl = "https://www.evopdf.com";  // or footer.HtmlSourceUrl = "https://…/footer.html"
footer.Height = 40;                              // points; or footer.AutoSizeContentHeight = true
footer.ShowInFirstPage = true;                   // ShowInOddPages / ShowInEvenPages
footer.ReserveSpaceAlways = true;                // default
footer.AutoResizePdfMargins = true;              // grow the page margin to make room
footer.PageNumberOffset = 0; footer.TotalPagesOffset = 0;

var header = converter.PdfDocumentOptions.PdfHtmlHeader;
header.Html = "<img src='logo.png' style='height:24px'>";
header.HtmlBaseUrl = "https://www.example.com/assets/";
header.Height = 50;
```
- Variables `{page_number}` and `{total_pages}` are replaced in the template (disable with `SkipVariablesParsing`).
- `FitHeight` scales the template to `Height`; `MinContentHeight` / `MaxContentHeight` bound auto-sizing.

## 2. Browser mode (simple, Chromium print header/footer)
```csharp
var o = converter.PdfDocumentOptions;
o.EnableHeaderFooter = true;
o.HeaderTemplate = "<div style='font-size:8px'><span class='title'></span></div>";
o.FooterTemplate = "<div style='font-size:8px'><span class='pageNumber'></span>/<span class='totalPages'></span></div>";
```
Uses Chromium's classes (`date`, `title`, `url`, `pageNumber`, `totalPages`). Less control than templates; no external resources.

## Migrating from Classic
Classic `PdfHeaderOptions` / `PdfFooterOptions` with `HtmlToPdfElement`, `TextElement` (`&p;`/`&P;`) and `LineElement` become one HTML template per header/footer — draw lines and text in HTML/CSS. `PageNumberingStartIndex` → `PageNumberOffset`.
